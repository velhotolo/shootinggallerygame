# 🎮 2D Lua Game

A simple 2D game developed to practice core game loop mechanics, state management, and object manipulation in Lua.

---

## 📖 Overview

This project was built as a hands-on milestone to get comfortable with Lua's syntax, tables, and execution flow. The core game logic and architectural setup follow the foundational design taught by Kyle Schaub in his Udemy game development course, adapted into a functional, runnable build.

---

## 🛠 Tech Stack

* **Language:** [Lua](https://www.lua.org/)
* **Engine/Framework:** [LÖVE (Love2D)](https://love2d.org/) *(ou ajuste se tiver usado outro framework)*
